# statsAndBooze

`statsAndBooze` is an R package developed as part of the *Coding for Data Science and Data Management* module. It provides simple utility functions to parse availability dates and find a common day for an happy hour among participants.

## Installation

You can install the development version of `statsAndBooze` from [GitHub](https://github.com/) with:

```r
# install.packages("pak")
pak::pak("SofiaaMaggioni/statsAndBooze")
